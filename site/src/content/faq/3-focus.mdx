question: How is this different from FOCUS?
---

They solve different parts of the same problem. FOCUS standardizes the billing
data you receive from providers, so costs from AWS, Azure, and others can be
represented in a common schema. AUDR standardizes the usage you emit when an
agent run happens, before that usage is priced.

The two are complementary. AUDR records can be rated by any backend and mapped
into FOCUS-compatible cost data. We are looking to complete the upstream half of
an existing standard, not stand up a competing one.
